# Options Road Map — client UI/UX preview

Live preview: https://unclejaweeyy.github.io/options-road-map-preview/

Includes the homepage, searchable learning library, and redesigned lesson workspace. The interface supports mobile and desktop layouts, course filters, bookmarks, local lesson progress, and personal notes.

This is a public design preview. Recordings and companion downloads were not supplied and display unavailable states. Notes and progress stay in the visitor's browser. No authentication or backend is included.

This repository contains only the static preview build. GitHub Pages publishes the main branch root. DM Sans license: assets/fonts/OFL.txt.
